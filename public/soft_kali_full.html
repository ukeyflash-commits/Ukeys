📚 Полный каталог программ (Kali Linux)

Все программы из списка с описанием и примерами использования.

0trace
Назначение: traceroute tool that uses existing TCP connections to map a network path. Позволяет выполнить трассировку маршрута, используя уже установленные TCP-соединения, что может помочь обойти некоторые фильтры.
0trace eth0 192.168.1.1 80
🔍 Сетевые утилиты
7zip
Назначение: 7-Zip file archiver with a high compression ratio. Работа с архивами (7z, zip, tar, gz и др.).
7z x archive.7z -ooutput_dir
📁 Файловые утилиты
aapt
Назначение: Android Asset Packaging Tool. Используется для просмотра, создания и обновления APK-файлов.
aapt dump badging app.apk
📱 Android
accountsservice
Назначение: Служба для управления пользовательскими аккаунтами, предоставляющая D-Bus интерфейс для запроса и изменения информации о пользователях.
dbus-send --system --print-reply --dest=org.freedesktop.Accounts /org/freedesktop/Accounts org.freedesktop.Accounts.ListUsers

Назначение: Утилиты для управления списками контроля доступа (Access Control Lists) в файловых системах.

Назначение: Kali тема для GTK3, основанная на Adwaita. Обеспечивает единый стиль для приложений GTK3.
(установка и применение через настройки внешнего вида)
🎨 Темы и оформление

Назначение: Стандартная тема значков по умолчанию для GNOME и GTK приложений.
(применяется автоматически в окружении GNOME)
🎨 Темы и оформление
afflib-tools
Назначение: Инструменты для работы с форматом Advanced Forensics Format (AFF), используемым в цифровой криминалистике.

🔬 Криминалистика

Назначение: ANSI color to HTML converter. Преобразует вывод терминала с цветами ANSI в HTML.

🔧 Сетевые утилиты
aircrack-ng
Назначение: Wireless WEP/WPA cracking. Комплект инструментов для аудита безопасности Wi-Fi сетей. Перехват пакетов, взлом WEP/WPA ключей.

📶 Wi-Fi Аудит

Назначение: Конфигурационные файлы для ALSA (Advanced Linux Sound Architecture), описывающие топологию звуковых устройств.
(используется системой для настройки звука)
🎵 Аудио
alsa-ucm-conf
Назначение: Конфигурационные файлы Use Case Manager для ALSA, определяющие, как настраивать звук для различных сценариев использования.
(используется системой для управления звуком)
🎵 Аудио
amap
Назначение: Next-generation scanning tool for application protocol identification. Определяет работающие сервисы и их версии, даже если они используют нестандартные порты.
