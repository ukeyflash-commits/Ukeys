🛠️ Каталог программ из списка (Kali Linux)

✨ Ниже представлены описания и примеры использования для основных инструментов ✨
0trace
Назначение: traceroute tool that uses existing TCP connections to map a network path.
Использование: Позволяет выполнить трассировку маршрута, используя уже установленные TCP-соединения, что может помочь обойти некоторые фильтры.
0trace eth0 192.168.1.1 80
🔍 Сетевые утилиты
7zip
Назначение: 7-Zip file archiver with a high compression ratio.
Использование: Работа с архивами (7z, zip, tar, gz и др.).
7z x archive.7z -ooutput_dir
📁 Файловые утилиты
aircrack-ng
Назначение: Wireless WEP/WPA cracking. Комплект инструментов для аудита безопасности Wi-Fi сетей.
Использование: Перехват пакетов, взлом WEP/WPA ключей.
aircrack-ng -w wordlist.txt -b 00:11:22:33:44:55 capture-01.cap
📶 Wi-Fi Аудит
amap
Назначение: Next-generation scanning tool for application protocol identification.
Использование: Определяет работающие сервисы и их версии, даже если они используют нестандартные порты.
amap -bq 192.168.1.1 21-25
🔍 Сканирование
amass
Назначение: In-depth DNS Enumeration and network mapping.
Использование: Сбор информации о поддоменах и внешней поверхности атаки.
amass enum -d example.com
🌐 Разведка
apktool
Назначение: Tool for reverse engineering Android APK files.
Использование: Декодирование ресурсов и манифеста, пересборка APK.
apktool d app.apk
📱 Реверс-инжиниринг
armitage
Назначение: Cyber attack management tool for Metasploit.
Использование: Графический интерфейс для управления атаками, визуализация целей и автоматизация.
armitage
💻 Эксплуатация
arp-scan
Назначение: ARP scanning and fingerprinting tool.
Использование: Обнаружение устройств в локальной сети с помощью ARP-запросов.
arp-scan --local
🔍 Сканирование
binwalk
Назначение: Tool library for analyzing, reverse engineering, and extracting firmware images.
Использование: Поиск встроенных файлов и данных в бинарных образах.
binwalk -e firmware.bin
🔧 Анализ
bloodhound.py
Назначение: Python ingestor for BloodHound, an Active Directory attack path graphing tool.
Использование: Сбор данных об AD для визуализации путей атак.
bloodhound-python -d domain.local -u user -p pass -c all
👥 Active Directory
burpsuite
Назначение: Platform for security testing of web applications.
Использование: Перехват и модификация HTTP/HTTPS трафика, сканирование уязвимостей.
burpsuite
🌐 Веб-безопасность
crackmapexec
Назначение: Swiss army knife for pentesting networks, often used with SMB, LDAP, WinRM.
Использование: Перебор паролей, выполнение команд, сбор информации в доменах Windows.
crackmapexec smb 192.168.1.0/24 -u user -p password
👥 Active Directory
crunch
Назначение: Tool for creating wordlists based on a character set and length.
Использование: Генерация словарей для перебора паролей.
crunch 8 8 0123456789 -o wordlist.txt
🔐 Взлом паролей
dirb
Назначение: URL bruteforcing tool to find hidden directories and files on web servers.
Использование: Перебор каталогов и файлов на веб-сервере.
dirb http://example.com /usr/share/wordlists/dirb/common.txt
🌐 Веб-безопасность
dnsenum
Назначение: Tool to enumerate DNS information about a domain.
Использование: Поиск поддоменов, DNS-записей, попытка зонной передачи.
dnsenum example.com
🌐 Разведка
dsniff
Назначение: Various tools to sniff and intercept network traffic (passwords, emails).
Использование: Пассивный перехват и анализ сетевого трафика.
dsniff -i eth0
👂 Перехват трафика
enum4linux
Назначение: Enumerates information from Windows and Samba systems.
Использование: Сбор информации о домене, пользователях, шаринг-ресурсах и политиках.
enum4linux -a 192.168.1.100
👥 Active Directory
ettercap
Назначение: Multipurpose sniffer/interceptor/logger for switched LAN.
Использование: ARP-спуфинг, перехват трафика, внедрение пакетов в Man-in-the-Middle атаках.
ettercap -T -M arp:remote /192.168.1.1// /192.168.1.10//
👂 Перехват трафика
evil-winrm
Назначение: The ultimate WinRM shell for pentesting.
Использование: Подключение к удаленным Windows системам через WinRM для выполнения команд.
evil-winrm -i 192.168.1.100 -u user -p password
💻 Эксплуатация
exploitdb
Назначение: Searchable Exploit Database (searchsploit).
Использование: Поиск готовых эксплоитов для известных уязвимостей.
searchsploit windows 10
💻 Эксплуатация
ffuf
Назначение: Fast web fuzzer written in Go.
Использование: Перебор директорий, файлов, параметров и многое другое.
ffuf -u http://example.com/FUZZ -w /path/to/wordlist
🌐 Веб-безопасность
gdb
Назначение: GNU Debugger.
Использование: Отладка исполняемых файлов, анализ стека, памяти и регистров.
gdb ./program
🔧 Реверс-инжиниринг
ghidra
Назначение: Software Reverse Engineering (SRE) framework.
Использование: Дизассемблирование, декомпиляция и анализ бинарных файлов.
ghidra
🔧 Реверс-инжиниринг
gobuster
Назначение: Directory/file & DNS busting tool written in Go.
Использование: Перебор директорий и поддоменов.
gobuster dir -u http://example.com -w /path/to/wordlist
🌐 Веб-безопасность
hashcat
Назначение: World's fastest and most advanced password recovery utility.
Использование: Взлом хешей паролей (GPU-ускорение).
hashcat -m 0 -a 0 hash.txt wordlist.txt
🔐 Взлом паролей
hydra
Назначение: Very fast network logon cracker supporting many services.
Использование: Брутфорс паролей для SSH, FTP, HTTP, RDP и других протоколов.
hydra -l user -P wordlist.txt ssh://192.168.1.1
🔐 Взлом паролей
john
Назначение: Active password cracking tool (John the Ripper).
Использование: Взлом хешей паролей различными методами (словарная атака, брутфорс).
john --wordlist=wordlist.txt hash.txt
🔐 Взлом паролей
kismet
Назначение: Wireless network and device detector, sniffer, wardriving tool.
Использование: Обнаружение Wi-Fi, Bluetooth и других беспроводных сетей.
kismet
